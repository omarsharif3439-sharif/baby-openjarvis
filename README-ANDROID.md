# OpenJarvis — Android স্টার্টার প্যাকেজ (শরিফের জন্য তৈরি)

এই প্যাকেজটা OpenJarvis-কে Android ফোনে ব্যবহারের উপযোগী করে সাজানো।
আগে একটা সত্যি কথা পরিষ্কার করে নেওয়া জরুরি:

## আসল ছবিটা — এটা যেভাবে কাজ করবে

OpenJarvis-এর AI মডেল (Qwen) ভারী সফটওয়্যার — এটা সরাসরি ফোনের ভিতরে
চালানো যায় না। তাই Android সংস্করণের বাস্তব গঠন হলো দুই অংশে:

1. **মাথা (সার্ভার)** — OpenJarvis + Qwen মডেল চলবে একটা কম্পিউটারে
   অথবা ক্লাউড সার্ভারে।
2. **মুখ (Android অ্যাপ)** — ফোনের অ্যাপটা শুধু সার্ভারের পর্দা দেখায়
   আর আপনার লেখা পাঠায়। ফোন হালকা থাকে, ব্যাটারিও বাঁচে।

এই প্যাকেজে দুই অংশেরই তৈরি জিনিস আছে।

## প্যাকেজে যা যা আছে

```
OpenJarvis-Android-Starter/
├── README-ANDROID.md            ← এই গাইড
├── server-config/
│   ├── config.toml              ← সার্ভারের সেটিংস (ছোট Qwen মডেল, ফোন থেকে যুক্ত হওয়ার মতো)
│   └── persona-baby-bangla.md   ← "Baby" নামের বাংলা-ভাষী সহকারীর আচরণ
└── android-app/                 ← Android অ্যাপের পুরো সোর্স কোড (Kotlin)
    └── app/src/main/java/com/sharif/baby/MainActivity.kt
                                 ← এখানে সার্ভারের ঠিকানা বসাতে হয় (SERVER_URL)
```

## ধাপ ১ — সার্ভার চালু করা (কম্পিউটার বা ক্লাউডে)

1. OpenJarvis ইনস্টল করুন (ওদের অফিসিয়াল ইনস্টলার দিয়ে)।
2. এই প্যাকেজের `server-config/config.toml` ফাইলটা কপি করুন:
   - Linux/Mac: `~/.openjarvis/config.toml`
   - Windows: `%USERPROFILE%\.openjarvis\config.toml`
3. `persona-baby-bangla.md` ফাইলটা OpenJarvis-এর
   `configs/openjarvis/prompts/personas/` ফোল্ডারে রাখুন।
4. সার্ভার চালু করুন:

   ```
   jarvis serve --host 0.0.0.0 --port 8000
   ```

   ওয়েব পর্দা (GUI) সহ চালাতে চাইলে ডকুমেন্টেশন অনুযায়ী `jarvis gui`
   ব্যবহার করুন — পর্দাটা সাধারণত http://localhost:5173 ঠিকানায় আসে।

## ধাপ ২ — Android অ্যাপ বানানো

1. `android-app` ফোল্ডারটা **Android Studio**-তে খুলুন
   (অথবা ক্লাউড বিল্ডার সার্ভিসে আপলোড করুন — যেমন GitHub-এ রেখে
   GitHub Actions দিয়ে APK বানানো যায়)।
2. `MainActivity.kt` ফাইলে `SERVER_URL`-এর জায়গায় নিজের সার্ভারের
   ঠিকানা বসান:
   - একই Wi-Fi-এর কম্পিউটার হলে: `http://192.168.1.100:5173`
     (নিজের কম্পিউটারের আসল IP বসান)
   - ক্লাউড সার্ভার হলে: `https://আপনার-সার্ভারের-ঠিকানা`
3. Build করে APK বানান, ফোনে ইনস্টল করুন।

> নোট: এই প্রজেক্টে Gradle wrapper-এর `.jar` ফাইলটা নেই।
> Android Studio দিয়ে প্রথমবার খুললেই সেটা নিজে তৈরি হয়ে যায়।
> অনলাইন বিল্ডার ব্যবহার করলে তাদের নিয়ম অনুযায়ী wrapper তৈরি করে নিন।

## ধাপ ৩ — ব্যবহার

ফোনে **Baby** অ্যাপটা খুললেই সার্ভারের চ্যাট পর্দা আসবে।
বাংলায় লিখুন — সহকারী বাংলাতেই উত্তর দেবে (persona অনুযায়ী)।

## নিরাপত্তা — খুব জরুরি

- সার্ভারটা **সরাসরি পাবলিক ইন্টারনেটে খোলা রাখবেন না** পাসওয়ার্ড ছাড়া।
  বাইরে থেকে ব্যবহার করতে চাইলে Tailscale বা Cloudflare Tunnel-এর মতো
  নিরাপদ টানেল ব্যবহার করুন।
- ক্লাউড সার্ভার ফ্রি টিয়ারে সীমিত থাকে — ছোট মডেল (qwen3.5:4b)
  বেছে দেওয়া হয়েছে ঠিক এই কারণেই।

## যা যা এই প্যাকেজে নেই (সত্যি কথা)

- তৈরি APK ফাইল নেই — সোর্স কোড আছে, APK বানাতে Android Studio
  বা ক্লাউড বিল্ডার লাগবে।
- ফোনের ভিতরে সরাসরি চলা AI মডেল নেই — মডেল সার্ভারেই চলে।
  এটাই এখনকার বাস্তবসম্মত পথ।
